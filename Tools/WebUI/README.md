# AiNiee WebUI

AiNiee-Next WebUI 即桌面 GUI 的界面层，采用 React / TypeScript / Vite。提供直接开始翻译/润色、完整任务队列、基于现有设置注册表的应用设置，以及同步运动的侧栏和页面导航。

## 开发

需要 Node.js 22.12+ 和可运行现有 API 的 Python 环境。从项目根目录执行：

```bash
npm --prefix Tools/WebUI ci
uv run python -m Tools.APIServer.server --host 127.0.0.1 --port 8000
npm --prefix Tools/WebUI run dev
```

浏览器打开 `http://127.0.0.1:5173`。Vite 只绑定回环地址，将 `/api` 代理到 `http://127.0.0.1:8000`，保留浏览器的 Host 与 Origin 以满足会话鉴权。开发时可用 `AINIEE_API_TARGET` 指定另一 API 地址；不要在浏览器中直连跨域 API。

```bash
AINIEE_API_TARGET=http://127.0.0.1:18791 npm --prefix Tools/WebUI run dev
```

## 构建与静态托管

```bash
npm --prefix Tools/WebUI run typecheck
npm --prefix Tools/WebUI run build
uv run python -m Tools.APIServer.server --host 127.0.0.1 --port 8000 --serve-web --web-dist Tools/WebUI/dist
```

打开 `http://127.0.0.1:8000`。`--web-dist` 是可选参数，只有开启 `--serve-web` 时使用；省略时保留原有静态目录。新版未替换 TUI 或旧 Web 启动入口。不要同时在同一端口启动两个后端。

`npm run preview` 只提供静态资源，不代理 API；完整功能请使用上述 API 托管方式。`node_modules/` 和 `dist/` 是本地依赖、构建产物，不应提交；本次未修改仓库 `.gitignore`。

## 结构和接口

- `src/App.tsx`：hash 导航和会话内草稿。
- `src/components/`：侧栏、文件导入和区域反馈。
- `src/pages/`：独立翻译/润色工作页、任务、设置及缓存编辑占位页。
- `src/api/`：后端 DTO 的独立投影、会话请求、单请求轮询与日志快照。
- `src/appearance/`：带版本的外观偏好。主题的同步首屏初始化另位于 `index.html`，变更存储键时须同步更新。
- `src/platform/adapter.ts`：浏览器传输、偏好存储与未来原生能力接口。

复用 `Tools/APIServer` 现有会话、配置名称、最近项目、上传、预检、队列、运行身份及任务状态接口。正式入口没有演示数据。点击“开始”或“开始队列”会实际启动任务，可能产生模型费用。设置页通过浏览器已认证通道读取配置，仅保留注册字段投影，保存差量与版本号，不展示或回写密钥。队列编辑器复用平台摘要、配置列表和运行参数 schema。

翻译与润色各有独立草稿，配置方案/源语言/目标语言共用一行；输出位置位于表单末尾默认折叠。翻译页的“翻译并润色”开关提交 all_in_one。源语言默认提交 `auto` 自动判断，目标语言默认继承配置；两侧都支持自定义语言。最近项目直接填入草稿的输入路径、方案和规则方案，不调用全局激活接口。点击拖拽区或“更换”统一打开应用自定义路径选择器；拖拽文件仍通过上传暂存，不调用系统原生文件选择器，不保留重复的选择入口。上传只使用默认保留策略，成功后用返回的真实服务器路径提交；取消或网络中断不保证服务器尚未完成暂存，重新导入不会覆盖同名文件。点击“开始”内部预检后直接启动；缺少提示词等错误就地显示。已有输出需要显式选择继续或归档，确认绑定具体输出路径；新的输出默认使用 cancel 策略防止竞态覆盖。提交不确定时不自动重试，要求核对任务后再决定。切页保留上传和表单状态，上传由用户取消或最终卸载时取消。

API client 使用同源 HttpOnly Cookie，仅遇到 `403` 与 `X-AiNiee-Auth-Required: web-session` 时恢复会话。GET 最多自动重试一次，所有写请求均不自动重放。请求取消和超时包含响应正文读取。

任务轮询串行读取运行身份、当前状态和队列；运行约 1 秒、空闲约 5 秒、后台约 15 秒，失败指数退避至最多 60 秒。任务页隐藏或卸载会中止轮询请求和计时器，返回使用已有内容静默刷新。运行身份、任务 ID 变化及日志游标重置会替换日志，最多保留 500 条。失败保留上次内容并提示过期。历史队列仅展示接口提供的信息，不请求或补造历史日志。

## 外观与桌面边界

CSS 变量集中在 `src/styles.css`：背景 `#FFF4F5`、内容面板 `#FFFCFC`、主按钮 `#D3E7D5`；深色为 `#211F22` / `#29262A`。控件、面板圆角为 10 / 16px。过渡 150–170ms，遵循减少动态效果设置。

外观页“UI动画”下拉默认开启，可关闭全部CSS过渡/动画及页面RAF运动/动态模糊。偏好仅保存在GUI本地；未来动画通过同一uiAnimations偏好管理。旧外观配置缺失此字段时默认开启，系统减少动态效果仍优先。

侧栏模式为 `auto | fixed`，默认自动。点击/键盘焦点进入时临时展开，点击外部或焦点移出时收起；固定模式保持展开。两种模式都覆盖内容，不改变主区域宽度，底部不再提供固定/折叠按钮。旧 pinned-open 偏好迁移为 fixed，其余旧模式迁移为 auto。

`usePageMotion` 的单个连续位置同时驱动侧栏滑块与页面轨道。导航顺序为翻译、润色、任务、设置；相邻页约 280ms，每跨一页增加约 280ms，采用 cubic ease-out。跨页经过实际中间页面并模糊，快速反向切换从当前位置继续；每帧位置同步、同时到达。页面保持挂载和各自滚动位置，避免切回时加载闪烁。翻译/润色页激活时静默刷新权限/配置摘要/最近项目，任务页仅在激活时轮询。减少动态效果时立即定位且关闭模糊。

设置页复用 `/system/settings-schema` 和现有 I18N，过滤只控制 CLI/TUI 菜单、引导和启动行为的条目：按类型生成控件；设置页常驻分类导航包含外观、15 个注册字段分类及备用池/自动化/接入说明，默认仅显示外观。搜索跨分类，切换保留修改与无效 JSON 草稿，未保存分类带提示；支持依赖、校验与差量保存。`media_*` 写入媒体设置接口，回复检查字段映射 `response_check_switch`，推理参数按所选平台保存到 `platforms`，替换规则由后端保存到规则方案；API 备用池、自动化规则使用对应现有接口。MCP接入页点击生成后复用已有Agent提示词构建器，展示实际项目快照/接入命令/协议提示词并支持复制，不启动服务或模型。自动化独立页留待后续设计，本轮保留现有配置入口。远程访问权限因后端要求保留 TUI 修改，显示为只读。

队列左侧只显示待执行/正在执行，右侧执行记录只读展示已知状态。支持添加、全参数编辑、移除、上移/下移、开始、停止；不提供会删除右侧历史的清空入口。成功记录右侧“文件编辑”导航到缓存编辑占位页，尚未读取或修改缓存。直接启动任务以本会话内存记录保留，刷新后仅可恢复后端实际提供的信息，不伪造历史。编辑按 UUID 与 revision 写差量，保留未改字段与 null/false/0 语义；不保存密钥。添加任务默认仅基础参数，执行方式、模型、批次、输出恢复及工作流统一收进默认折叠的“高级参数”。运行参数覆盖按后端 schema 生成，工作流/分步对象使用结构化 JSON 编辑。运行、锁定、只读和读取失败时禁止不适用的写操作。

本轮未接入 Tauri。未来需提供完整 `PlatformAdapter`，处理请求来源、Cookie、原生文件选择权限与窗口生命周期，不能仅修改 API URL。路径控件通过受Web会话保护的 `/api/files/browse` 选择运行主机上的真实文件/目录，只返回有界目录元数据且拒绝MCP通道，不读取文件内容。浏览器不伪造客户端绝对路径；未来Tauri可适配原生选择器。尚未提供原生打开输出和窗口按钮。

设置默认在有效输入稳定600ms后自动保存，串行写入并保留保存途中编辑。成功保存后提供最近最多10次内存撤销，刷新即清空；撤销先核对目标值与配置方案，再使用最新revision写逆向差量，不覆盖其他位置的改动。网络错误暂停重试、409保留草稿等待重新加载；媒体/平台/回复检查沿用各自实际存储路径。备用池和自动化规则同样自动保存，规则不完整时等待修正，不启动调度器。

高级折叠和滑条推荐范围只存在于 `settingsPresentation.ts` / `numericPresentation.ts`，不修改共享注册表和TUI。SDK、推理参数、依赖下载源、漏翻检测次数/阈值、智能轮次、自定义限流/RPM/TPM和全部漫画配置保留普通显示；缺失SDK模式用OpenAI，显式旧选择保留。行数/Token限制合并一项，分别保留两套数值。数值滑条推荐范围与后端有效范围分离，手输不被滑条范围截断；无效/未完成输入不保存。

预设 `Resource/platforms/preset.json` 默认开启重复句翻译记忆、翻译后格式转换及仅导出时格式转换；自动跟随输入输出路径和智能轮次原已开启并保留。个人Profile的显式值仍优先，不强行覆盖。

MCP 接入页按三步引导：选择支持 MCP 和本地工具的 Agent 客户端，生成并复制提示词发给 Agent，待 Agent 确认工具可用后说明任务。提供 Codex CLI、Claude Code、Cursor、VS Code + GitHub Copilot、Qwen Code、CodeBuddy Code 的官方 MCP 文档，以及 WorkBuddy、千问办公（千问 PC 客户端）、豆包电脑版的官方入口。具体版本须支持 MCP 和本地工具；客户端需要能访问项目目录，并允许 Agent 执行本地命令及配置 MCP。配置与连接检查交给 Agent 完成，入口列表不表示已实测每个客户端的接入。

## 双层 I18N

项目语言包保留在根目录 `I18N/{locale}.json`，用于已有配置标签、说明、选项；GUI语言包在 `src/i18n/locales/{locale}/{domain}.json`，用于页面、按钮、状态、错误和GUI专属字段表述。两套共存，不复制或改写项目语言包。

统一 `t(key, parameters?, fallback?)` 查找顺序为：当前语言GUI包 → 当前语言项目包 → 英文GUI包 → 英文项目包 → 显式回退/键名。GUI键采用 `gui.*`，需要覆盖原项目键时可在GUI的overrides.json定义同名键。支持 `{name}` 命名插值，用户文件名/路径/日志不自动翻译。GUI描述若需覆盖，可在专属包提供同名description_key。

7种语言与项目一致：zh_CN、zh_CNTW、en、ja、ko、ru、es。外观页界面语言仅更新本地GUI偏好，不写项目interface_language。语言包按需加载并缓存，启动时先加载再挂载UI；切换保留页面草稿与撤销状态。已产生的后端错误/运行日志原样保留，已有瞬时通知可能保留发生时语言。

新增文本必须进入对应domain语言包，7种语言键集合和占位符保持一致；不要在模块顶层调用t()固定翻译，组件渲染或操作发生时查词。新增域会由i18n loader自动发现。所有控件不新增国际化依赖。

项目LOGO为用户原图 `public/logo.jpg`，原字节保留；页面title、favicon和侧栏品牌为AiNiee-Next。
