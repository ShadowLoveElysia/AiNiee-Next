# AiNiee-Next

[简体中文](../README.md) | [English](README_EN.md) | [繁體中文](README_zh_CNTW.md) | [日本語](README_JA.md) | [한국어](README_KO.md) | [Русский](README_RU.md) | [Español](README_ES.md)

AiNiee-Next — инструмент пакетного перевода на основе больших языковых моделей. Он поддерживает обработку романов, электронных книг, документов, субтитров, игровых текстов, манги и субтитров к аудио и видео в реальном времени.

Основной интерфейс — командная строка и интерактивные меню терминала (CLI/TUI). Также доступны веб-панель, настольное окно и интерфейсы MCP и Skills для внешних ИИ-клиентов. Программа подходит как для быстрого перевода одного файла, так и для длительной работы с многотомными сериями и пакетными задачами.

[Скачать ZIP с последними исходниками](https://github.com/ShadowLoveElysia/AiNiee-Next/archive/HEAD.zip) — Полная копия исходного кода последнего коммита ветки по умолчанию. Сначала распакуйте архив; пользователям Windows следует открыть папку распакованного проекта и запустить `Windows prepare.bat`, затем `Windows launch.bat`.

## Быстрый старт

### 1. Подготовка базового окружения

Проекту необходимы Python 3.12 и менеджер пакетов `uv`. В корне репозитория находятся скрипты подготовки для каждой платформы. При первом использовании запустите соответствующий скрипт, чтобы автоматически настроить базовое окружение:

- **Windows**: дважды щёлкните `Windows prepare.bat`.
- **Linux**: выполните в терминале `bash "Linux prepare.sh"`.
- **macOS**: дважды щёлкните `Mac prepare.command`.

Если вам нужен только перевод текстов, электронных книг, субтитров или игровых сценариев, после этого шага можно начинать работу. Манга, синхронный перевод и перевод видео требуют дополнительных окружений для моделей компьютерного зрения или речи. При необходимости установите их отдельно по инструкциям шага 5 ниже.

### 2. Запуск и первоначальная настройка

После подготовки базового окружения откройте программу с помощью скрипта запуска для вашей платформы:

- **Windows**: дважды щёлкните `Windows launch.bat`.
- **Linux**: выполните `bash "Linux launch.sh"`.
- **macOS**: дважды щёлкните `Mac launch.command`.

Также можно запустить программу из командной строки в корне проекта: `uv run ainiee_cli.py`.

При первом запуске откроется мастер настройки. Выполните два шага:

1. Выберите язык интерфейса (поддерживаются семь языков: упрощённый и традиционный китайский, английский, японский, корейский, русский и испанский).
2. Выберите способ перевода:

   - **Режим API (самый распространённый)**: выберите платформу в разделе управления API. Поддерживаются OpenAI-совместимые API, Anthropic, Google, DeepSeek и интерфейсы локальных моделей, например Sakura / LocalLLM. Введите адрес API, ключ API и название модели, проверьте подключение и сохраните настройки.
   - **Режим внешнего Agent**: если вы хотите переводить за счёт квоты внешнего ИИ-помощника или клиента для программирования, следуйте указаниям мастера, чтобы включить MCP или руководство по внешнему подключению.

### 3. Первая задача перевода текста или электронной книги

1. В главном меню выберите входной файл или папку целиком, затем задайте исходный язык, язык перевода и путь вывода.
2. При необходимости настройте и включите глоссарий, описания персонажей или собственные промпты в меню правил и промптов. Параметры выполнения и правила произведения хранятся отдельно, поэтому при смене произведения не нужно повторно настраивать API.
3. Подтвердите настройки и начните перевод. Во время работы можно в любой момент приостановить задачу, изменить число параллельных запросов или переключиться на резервный ключ.
4. Если соединение прервалось или вы остановили задачу вручную, при следующем запуске выберите тот же проект и восстановите кэш, чтобы продолжить с места остановки. Уже переведённые фрагменты не будут запрошены повторно.
5. После завершения перевода можно сразу экспортировать результат или сначала проверить его во встроенном редакторе терминала либо с помощью инструментов корректуры.

### 4. Запуск веб-панели или настольного приложения

Если вам удобнее работать в браузере, особенно для просмотра статистических графиков, постраничного редактирования кэша или работы с редактором манги, запустите веб-панель из главного меню терминала. Также можно воспользоваться скриптами запуска настольного приложения из командной строки:

- **Windows**: запустите `Tools\TauriShell\LaunchGUI.bat`.
- **Linux / macOS**: запустите `Tools/TauriShell/LaunchGUI.sh`.

### 5. Использование манги, синхронного перевода и офлайн-видео

Эти три модуля требуют объёмных зависимостей для инференса и моделей. Перед первым использованием запустите соответствующий скрипт подготовки дополнительного окружения:

- **Перевод манги**:

  - Подготовка окружения: в Windows запустите `Windows comic prepare.bat`, в Linux/macOS — `Unix comic prepare.sh`.
  - Использование: откройте редактор манги в веб-панели для визуального редактирования и экспорта либо запустите пакетную обработку командой `uv run ainiee_cli.py manga <INPUT_PATH>`.

- **Синхронный перевод и офлайн-видео**:

  - Подготовка окружения: в Windows запустите `Windows media prepare.bat`, в macOS — `Mac media prepare.command`. Если в Linux/WSL используется отдельный сервис распознавания речи vLLM, дополнительно запустите `Linux qwen vllm prepare.sh`.
  - Использование: откройте нужный режим через главное меню или выполните `uv run ainiee_cli.py live` (субтитры в реальном времени; в macOS также можно дважды щёлкнуть `Mac live launch.command`) и `uv run ainiee_cli.py video` (офлайн-видео).

## Основные возможности

### Тексты, электронные книги и локализация игр

- **Подстановка только нужных данных**: в запрос включаются лишь те термины глоссария и слова, запрещённые к переводу, которые встречаются в текущем фрагменте. Поддерживаются английские словоформы и проверка границ слов, что уменьшает влияние посторонней информации на модель.
- **Вызов данных персонажей и хронология по томам**: имена, псевдонимы, уважительные обращения, личные местоимения и речевые привычки в соседних строках позволяют автоматически подставлять данные присутствующих персонажей. Для многотомных романов изменения персонажей и мира можно записывать по номерам томов, чтобы в ранние тома не попадали варианты имён, появляющиеся только позже.
- **Несколько источников согласованности (необязательно)**: доступны память переводов для повторяющихся длинных предложений в рамках проекта, поиск прошлых переводов по локальным ключевым словам, а также краткие изложения сюжета и память о персонажах через вызовы инструментов. При включении режима памяти обработка автоматически становится однопоточной для сохранения порядка.
- **Обработка ошибок и дополнение пропусков**: автоматически защищает блоки кода, плейсхолдеры, переносы строк и пробелы в начале и конце текста. В ответах проверяются число строк, номера и остатки текста на иностранном языке. Если в пакете пропущено лишь несколько строк, они переводятся отдельно и возвращаются на свои места без повторного перевода всего пакета.
- **Литературная правка и проверка корректуры**: поддерживает отдельный процесс литературной правки, проверки символов и плейсхолдеров по правилам и предложения ИИ-корректора. Предложения сохраняют отпечаток исходного текста; их можно по одному принимать, отклонять или отменять в терминале либо веб-панели, не перезаписывая по ошибке вручную исправленный перевод.
- **Инструменты работы с электронными книгами**: консервативное чтение нестандартных EPUB (с фильтрацией текстового шума и японских аннотаций ruby), извлечение вложенного текста и запись перевода в исходную структуру книги, синхронизация кодировок и объявлений, синхронизация переведённого оглавления и названий глав, переключение горизонтального и вертикального набора, снятие принудительного шрифта и размера, готовые стили абзацев, исправление локальных ссылок, сжатие изображений и преобразование в WebP с обновлением ссылок, двуязычные EPUB, настройка метаданных языка и названия книги, определение номеров томов и единообразные имена, метаданные серий и автоматическое пакетное объединение, автоматическое разбиение TXT на главы с преобразованием в EPUB и нормализация кавычек при переводе с японского на китайский. Настройки экспорта можно изменить и повторно экспортировать книгу из кэша переводов. Также включены скрипт пакетного объединения серий электронных книг (`Tools/Ebook/批量电子书整合.py`) и инструменты извлечения игровых текстов (`Tools/StevExtraction`).

### Перевод манги и веб-редактор

- Импортирует изображения, папки, ZIP/CBZ, RAR/CBR и PDF, объединяя обнаружение реплик и текста, OCR, пакетный перевод, восстановление фона и автоматическую вёрстку с рендерингом.
- Встроенная проверка качества помечает страницы для ручной проверки при аномальном снижении возможностей модели, пропущенных символах или выходе текста за границы и не позволяет сразу экспортировать их как готовый результат.
- Веб-интерфейс предоставляет полноценный редактор слоёв: настройку положения и стиля текстовых блоков, перерисовку масок восстановления кистью, повторный запуск отдельного этапа для одной страницы, отмену и повтор действий. Поддерживается экспорт изображений, PDF, CBZ, ZIP, EPUB и многослойных PSD-файлов (или JSX-скриптов).

### Синхронный перевод и офлайн-видео

- **Синхронный перевод**: захватывает системный звук или звук дерева процессов выбранного приложения. В Windows можно захватывать только выбранную программу или игру, не смешивая звук других приложений; в macOS используется нативный Helper. После сегментации речи, распознавания и перевода локальной моделью субтитры отображаются в плавающем окне. Включает глоссарий для стримеров и отдельное приватное окно двустороннего текстового перевода.
- **Офлайн-видео**: автоматически извлекает аудио, подавляет шум, распознаёт речь и упорядочивает временную шкалу субтитров. Можно сочетать локальные модели и облачные API; итоговый результат оформляется через FFmpeg как MKV с отдельной дорожкой субтитров или MP4 с вшитыми в изображение субтитрами.

### Автоматизация и внешнее подключение

- **Очереди, расписания и наблюдение за папками**: поддерживает очередь задач (ожидающие задачи можно редактировать и во время выполнения очереди), расписания Cron и автоматическое наблюдение за папками. Новые файлы добавляются в очередь после стабилизации записи; поддерживается порядок томов серии.
- **MCP / Skills / Docker**: поддерживает запуск MCP Server (stdio / streamable-http / SSE) и сервисов Skills HTTP/CLI. Перевод с помощью модели можно передать внешним ИИ-клиентам, а чтением файлов, проверками и атомарной записью результата занимается AiNiee. Для развёртывания в контейнере см. `Tools/Docker/Dockerfile`.

## Частые операции командной строки

Помимо интерактивных меню, все основные задачи можно запускать напрямую из командной строки для использования в скриптах и автоматизации:

```bash
# Перевести файл или папку, указать вывод и языки, автоматически продолжить задачу
uv run ainiee_cli.py translate INPUT_PATH -o OUTPUT_PATH -s Japanese -t Chinese --resume --yes

# Только правка / перевод с правкой / только экспорт из кэша (без вызова модели)
uv run ainiee_cli.py polish INPUT_PATH --yes
uv run ainiee_cli.py all_in_one INPUT_PATH --yes
uv run ainiee_cli.py export INPUT_PATH --yes

# Пакетная обработка манги (сначала проверить локальные модели и устройство)
uv run ainiee_cli.py manga INPUT_PATH --manga-runtime-check
uv run ainiee_cli.py manga INPUT_PATH --yes

# Сразу открыть синхронный перевод или перевод офлайн-видео
uv run ainiee_cli.py live
uv run ainiee_cli.py video

# Запустить MCP Server или сервис Skills
uv run ainiee_cli.py mcp --mcp-transport stdio
uv run ainiee_cli.py --skills
python Tools/Skills/cli.py list
```

Для просмотра всех параметров командной строки выполните `uv run ainiee_cli.py --help`.

## Поддерживаемые форматы файлов

| Категория | Форматы | Примечания |
| :--- | :--- | :--- |
| Обычный текст | `.txt`, `.md` | Построчное извлечение и запись; в Markdown автоматически пропускаются строки только с изображениями и определения ссылок |
| Электронные книги | `.epub` | Разбор внутренней структуры и оглавления с записью перевода |
| Документы Office | `.docx`, `.pptx` | Извлечение и запись текстовых узлов или абзацев текстовых блоков; текст на изображениях в PPTX не распознаётся, часть смешанного форматирования внутри абзацев упрощается |
| Электронные таблицы | `.csv`, `.xlsx` | CSV читается и записывается напрямую; XLSX разбивается на CSV для перевода и затем собирается обратно. Сложные формулы и оформление не сохраняются; подходит для простых текстовых таблиц |
| Субтитры и тексты песен | `.srt`, `.vtt`, `.ass`, `.lrc` | Сохраняет временную шкалу и теги стилей, заменяя только текст |
| Проекты локализации | `.po`, `.json` | PO пока обрабатывает записи в единственном числе; JSON автоматически распознаёт структуры i18next, Paratranz, MTool и другие |
| Игровые проекты | Ren'Py, Translator++, VNText | Извлечение и запись с учётом специализированного формата |
| PDF | `.pdf` | Использует BabelDOC для извлечения абзацев и записи с восстановлением вёрстки; результат для сканов зависит от условий OCR |
| Старые форматы Office | `.doc`, `.ppt` и другие | Только Windows; требуется установленный Microsoft Word |
| Другие электронные книги | `.mobi`, `.azw3`, `.fb2` и другие | Необходимо установить и включить Calibre; файлы преобразуются для обработки, затем преобразуются обратно |

## Примечания

1. **Область перевода видео**: офлайн-обработка видео пока работает только с речью в аудиодорожке и не распознаёт текст, встроенный в кадры. Автоматическое извлечение терминов для длинных видео сейчас отправляет всю расшифровку модели одним запросом (разбиение по бюджету ещё не реализовано). Для очень длинных видео рекомендуется заполнить глоссарий вручную или использовать модель с длинным контекстом.
2. **Внешние инструменты**: для экспорта манги в многослойный PSD необходим локально установленный Photoshop, иначе доступен только экспорт JSX-скриптов. Для сжатия и распаковки RAR/CBR в системе должны быть соответствующие внешние инструменты командной строки.
3. **Безопасность удалённого доступа**: веб-панель по умолчанию слушает только локальный loopback-адрес. Встроенная проверка сессий в основном предотвращает межсайтовое злоупотребление локальными API и не является многопользовательской системой учётных записей и прав. При удалённом доступе используйте доверенную внутреннюю сеть либо разместите перед панелью обратный прокси с аутентификацией доступа.
